# Gefühlskompass PWA V0.25

- Modellmigration auf Version 2, damit aktuelle gewichtete Standardregeln tatsächlich verwendet werden.
- Eigene Situationen, Körperregionen, Bedürfnisse, Farben und zusätzliche Untergefühle bleiben erhalten.
- Alle Untergefühle in Schritt 5 alphabetisch mit Suche.
- Katalogsuche und Sortierung alphabetisch/nach Hauptgefühl.
- Abweichende Hauptgefühle können nun tatsächlich ausgewählt werden.

Optik, Fragestellungen und Dialogreihenfolge bleiben unverändert.
